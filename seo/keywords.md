## 5 Pillar Guide Pages

All live under a `/guides/` hub (per the site's content-collection architecture). Slugs below are recommended; the collection makes renaming a one-line change if you want to adjust later.

### 1. RAG — `/guides/rag`
- **Primary keyword (H1, title, first 100 words):** `retrieval augmented generation` (9,900/mo, **KD 74 — hard**). This is a genuine cornerstone target: rank for it over time via comprehensive coverage + backlinks, not a quick win. Use the full term "Retrieval-Augmented Generation (RAG)" in the H1 so both the spelled-out and abbreviated searches match.
- **Secondary keywords for H2s:** rag examples, rag architecture, chunking strategies (fold in the thin "chunking strategies rag" term here), hybrid search & reranking (fold in here too), vector database embeddings.
- **Intent:** informational — write it as the definitive practitioner explainer, not a product pitch.

### 2. MCP — `/guides/mcp`
- **Primary keyword:** `model context protocol` (12,100/mo, KD 58 — moderately hard but very achievable given it's a newer, more specific term than RAG).
- **Secondary keywords for H2s:** model context protocol specification, model context protocol anthropic, mcp vs function calling / tool calling.
- **Intent:** informational.

### 3. LLM Evaluation (Evals) — `/guides/llm-evaluation`
- **Primary keyword:** `llm evaluation` (1,000/mo, KD 23 — very achievable, a realistic near-term ranking target).
- **Secondary keywords for H2s:** llm evaluation framework (390/KD17), llm evaluation tool (110/KD22), llm observability and evaluation (fold in observability content).
- **Intent:** informational.

### 4. AI Agents — `/guides/ai-agents`
- **Primary keyword:** `ai agents` (49,500/mo, **KD 67 — hard**). Keep this as the H1/title term since it's the exact topic and brand-relevant, but treat it as a long-horizon cornerstone target — don't expect to outrank incumbents quickly. To get faster traction, make the page's early H2s target the much easier related terms: `ai agents examples` (1,600/KD18), `ai agents vs agentic ai` (1,300/KD15), and weave in `ai orchestration` (1,300/KD11) and `ai agent memory` (210/KD31) as dedicated sections — those sections can realistically rank on their own and pull traffic to the page while the head term builds authority.
- **Intent:** commercial (buyers researching agent platforms/vendors) — good fit for the "Talk to me about AI" CTA.

### 5. Voice AI Agents — `/guides/voice-ai-agents`
- **Primary keyword:** `voice ai agents` (720/mo, KD 38 — achievable).
- **Secondary keywords for H2s:** ai voice agent platform (880/KD44), conversational ai voice agents (1,300/KD34), voice ai agents for developers (20/KD35).
- **Intent:** commercial.
